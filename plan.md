# Kế hoạch Dự án: Matheuristics for Flexible Multi-Period Vehicle Routing with Time Windows

## 1. Mục tiêu
Giải quyết bài toán vận tải B2B kết hợp hai yếu tố:
- **Tối ưu Lộ trình:** Multi-period CVRP với Time Windows (Matheuristics).
- **Tối ưu Xếp hàng 3D:** LIFO, Constraints về kích thước, trọng tải.

## 2. Các giai đoạn (Phases)
- **Phase 1:** Core DB & Schema.
- **Phase 2:** API Management (Laravel).
- **Phase 3:** Python Solver Integration.
- **Phase 4:** Real-time Dashboard & 3D/Map View.
- **Phase 5:** Backtesting & Finalization.
